コード進行プレイヤー

定番のコード進行をキーを変えて再生できます。各コードは1小節ずつ鳴ります。メトロノームと合わせて使うと、次の拍の頭から自動でぴったり始まります。

「コード検索」タブでコードを集めて、名前を付けて保存するとここから選べます。

スケール表示

ルート音とスケールの種類を選ぶと、鍵盤上に構成音がハイライトされます。

コード検索

コードネームを入力すると構成音を調べて鳴らせます。ルートと種類から選ぶこともできます。

対応表記: m / maj7 / m7 / 7 / dim / dim7 / aug / sus2 / sus4 / 6 / m6 / add9 / maj9 / m9 / 9 (シャープは # 、フラットは b)

作成中の進行

「進行に追加」でコードを集めると、ここに並びます。クリックで削除できます。

保存した進行はこのブラウザに保存され、次回このページを開いたときも残ります。「コード進行」タブのプルダウンから選んで再生できます。

メトロノーム

上部のテンポに合わせてクリック音を鳴らします。拍子はプルダウンで変更できます。

鍵盤

鍵盤をクリック(タップ)すると自由に音を鳴らせます。指で押さえたままドラッグして弾くこともできます。

鍵盤を押すとここに音名が表示されます。

PCキーボードでも演奏できます: A=ド W=ド# S=レ E=レ# D=ミ F=ファ T=ファ# G=ソ Y=ソ# H=ラ U=ラ# J=シ K=高いド

すべての音はブラウザ内で合成しています(音源ファイルの再生ではありません)。ヘッドホン推奨。
